# Bokningssystem

Detta är ett bokningssystem i C# där användaren kan hantera bokningar av mötesrum.

## Starta programmet

1. Öppna projektets `.sln`-fil i Visual Studio.
2. Välj bokningssystemets konsolapplikation som startprojekt.
3. Tryck på **Ctrl + F5** för att starta programmet.
4. Använd menyn i konsolen för att hantera bokningar.

## Köra enhetstester

1. Öppna projektet i Visual Studio.
2. Klicka på **Test → Test Explorer**.
3. Klicka på **Run All** för att köra enhetstesterna.
4. I Test Explorer visas vilka tester som lyckades och vilka som misslyckades.

## Teknik

- C#
- .NET
- xUnit för enhetstester
